# hello-claude-pr

A tiny calculator library, created to practise opening a first pull request.

## Usage

```python
from calculator import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 3)  # 2
multiply(4, 2)  # 8
divide(10, 2)   # 5.0
```
